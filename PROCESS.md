## Tools
ChatGPT: Helped me explore possible topics, and find the correct website and direct download link for the climate dataset. 
VS Code: Used to edit and run my Python scripts.
GitHub: Used to store my code, data, and project documentation.
Our World in Data: Provided the global temperature anomaly data related to El Niño and La Niña. ChatGPT gave me the link.

## Kept

I kept the idea of using historical climate data to explore changes over time. I chose global temperature anomalies linked to El Niño and La Niña because the data was available in a clear, structured format. This made it easier to focus on the visualisation instead of spending too much time preparing the data.

## Rejected

I spent a lot of time looking for data about dust storms, which was the climate phenomenon I was most interested in. I found it fascinating because I wanted to show how dust plumes spread and change over time. However, the dataset was too large, with around 16 GB of data for each year. I could not find a simple, smaller dataset within the limited time available. In the end, I decided to give up on this topic and choose global temperature data instead.
